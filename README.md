# 同屏·被查看端（安卓 APK）— 云端编译傻瓜教程

被查看的**安卓手机**装上这个 App，授权一次屏幕采集后后台常驻推流；你（查看端）随时打开网页就能看到它的实时画面，**不用对方每次同意，也不用同一 Wi-Fi**。

> iPhone 不能当被查看端（苹果禁止后台录屏），但可以当查看端。
> 手机浏览器也做不到网页录屏（系统限制），所以被查看端**必须装这个 APK**。

**你不需要安装 Android Studio**，用 GitHub 免费云端编译即可。全程约 20 分钟，只需做一次。

---

## 第一步：注册 GitHub（已有账号可跳过）

打开 https://github.com → 点右上角 **Sign up** → 用邮箱注册 → 邮箱里点验证链接。

---

## 第二步：新建仓库

1. 登录后，点右上角 **+** → **New repository**
2. Repository name 填：`phonemirror`
3. 选 **Public**（公开，免费编译额度才够用）
4. 勾选 **Add a README file**
5. 点绿色 **Create repository**

---

## 第三步：上传代码（关键）

1. 进到刚建的 `phonemirror` 仓库页面
2. 点中间偏上的 **Add file** → **Upload files**
3. 把 `android-sender` **文件夹里面的所有内容**拖进去（不是拖文件夹本身）：
   - `.github` 文件夹（里面是自动编译脚本）
   - `app` 文件夹
   - `build.gradle`、`settings.gradle`、`gradle.properties`
   - `README.md`
4. 页面最下方 **Commit changes** 那里，点绿色按钮 **Commit changes**

> ⚠️ 拖进去后，如果列表里看不到 `.github`（点号开头的文件夹），说明没拖上——
> 文件夹在 Windows 里可能隐藏，请回到 `android-sender` 文件夹确认能看到 `.github`，
> 再单独把它拖进去。没有它就不会自动编译。

---

## 第四步：等它自动编译

1. 上传完，点仓库页面顶部的 **Actions** 标签
2. 会看到一个叫 **Build APK** 的任务正在跑（黄色圆点=进行中，绿色✓=完成）
3. 点进去可以看实时日志，**约 5~10 分钟**
4. 变绿后，点这个任务 → 页面最下方 **Artifacts** 区域出现
   `phonemirror-sender-apk` → 点它下载（是个 zip）

> 如果变成红色 ✗：点进去看红色报错，把报错截图发给我，我改好后你重新上传即可。

---

## 第五步：装到被查看的安卓手机

1. 下载的 zip 解压，得到 `app-debug.apk`
2. 传到那台安卓手机（微信"文件传输助手"/数据线/QQ 都行）
3. 手机点开 apk → 允许"未知来源安装" → 安装
4. 桌面出现「**同屏·被查看**」图标

---

## 第六步：开始使用

**被查看的安卓手机：**
1. 打开「同屏·被查看」
2. 服务器地址**已经预填好了**（`https://111.229.194.208:3443`），房间号 `Kx7m2Qp9`，不用改
3. 点「**开始投屏**」→ 弹「是否允许截取屏幕上显示的所有内容」→ 点「**立即开始**」
4. 状态栏出现常驻通知 → 之后一直在后台推流，**不用再点**

**你自己的手机（查看端）：**
浏览器打开 `https://111.229.194.208:3443/viewer.html`，房间号填 `Kx7m2Qp9` → 连接 → 看到实时画面。

---

## 以后怎么更新

改了代码后，重复**第三步**上传覆盖即可，GitHub 会自动重新编译出新 APK。

---

## 常见问题

**Q：手机重启后还要重新授权吗？**
要。安卓系统的安全底线，任何 App 都绕不过。重启后打开 App 再点一次"开始投屏"。建议在系统设置里把它加入"自启动/电池优化白名单"，减少被清理。

**Q：看不到画面/一直转圈？**
- 确认被查看端 App 状态栏通知还在（说明服务活着）
- 确认两端房间号一致
- 若两端都在 4G/严格 NAT 下，服务端 `turn.json` 已配好 openrelay 中继兜底

**Q：APK 会过期吗？**
不会，装上去就能一直用。

**合规提醒**：仅用于你拥有或已获授权的设备。
